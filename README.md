# Картотека — установщики

Публичные выпуски настольного приложения для работы с картотекой арбитражных дел.
Здесь размещаются только установщики, контрольные суммы и манифест обновления. Исходники и пользовательские базы не публикуются.

## Скачать и обновить

Откройте [последний выпуск](https://github.com/germanpreobrazenskij19-code/kad-parser-downloads/releases/latest).

- Windows x64: скачайте `KadParser-Setup-Windows-*.exe`.
- Mac с Apple Silicon: скачайте `KadParser-Mac-AppleSilicon-*.pkg`.

Закройте Картотеку и запустите установщик поверх прежней версии. Не удаляйте папку данных: картотеки и настройки хранятся отдельно от программы.

Версии до 1.7.11 используют прежний канал Vercel Blob, который сейчас приостановлен. Для перехода на новый канал установите 1.7.11 вручную один раз. Дальше используйте кнопку «Обновить программу».

## Подключить Google Диск

1. Установите [Google Диск для компьютера](https://www.google.com/drive/download/) и войдите в свой аккаунт.
2. В Картотеке откройте нужную картотеку и нажмите «Google Диск» внизу окна.
3. Нажмите «Синхронизировать с папкой Google Диска» и выберите локальную папку на Google Диске.
4. Проверьте параметры и нажмите «Подключить и записать дела».

Программа создаёт отдельный Excel для каждой картотеки и дополняет его без дублей. Google Диск для компьютера синхронизирует файл с облаком; статус загрузки проверяется в Google Диске. Это синхронизация файла Excel через папку, а не авторизация Google внутри Картотеки и не создание нативной Google Таблицы.

Автопроверка новых дел включается отдельно и работает, пока программа и компьютер включены. Изменение папки само по себе не отправляет сохранённые дела — запись начинается после подключения.
